# ChromeOS: References

Always prefer Google's current ChromeOS and Chromebook help pages; settings menus and policies change
between releases. Re-verify links and contents when updating this skill.

Last verified: 2026-10-31

## Vendor (authoritative)

- Auto Update policy table (per-model Auto Update Expiration dates):
  https://support.google.com/chrome/a/answer/6220366
- Ten years of automatic updates (policy, extended-update opt-in for some older devices):
  https://support.google.com/chrome/a/answer/14328032
- Check your Chromebook's update schedule: https://support.google.com/chromebook/answer/9367166
- Update your Chromebook's operating system (About ChromeOS > Additional details):
  https://support.google.com/chromebook/answer/177889
- Chrome Releases blog (security fixes for Chrome and ChromeOS): https://chromereleases.googleblog.com/
- Reset (powerwash) your Chromebook: https://support.google.com/chromebook/answer/183084
- Set up Linux on your Chromebook: https://support.google.com/chromebook/answer/9145439
- Install Android apps on your Chromebook: https://support.google.com/chromebook/answer/7021273
- Family Link help (supervising a child's Google account and devices):
  https://support.google.com/families/answer/7680868
- Differences between ChromeOS Flex and ChromeOS (no verified boot or security chip; firmware updated by
  the hardware maker): https://support.google.com/chromeosflex/answer/11542901
- ChromeOS Flex deployment best practices (certified models, TPM):
  https://support.google.com/chromeosflex/answer/12024393
- Chromium OS developer mode (what it disables, how to enter and leave it):
  https://www.chromium.org/chromium-os/developer-library/guides/device/developer-mode/
- Chromium OS verified boot design: https://www.chromium.org/chromium-os/chromiumos-design-docs/verified-boot/
- Google Account security checkup: https://myaccount.google.com/security-checkup

Generic vulnerability and incident sources (CISA KEV, NVD, CVE, CISA ransomware guidance, IC3) are listed in
the core documents.

## Third-party (not authoritative)

- Reporting in 2025 and 2026 (for example Android Authority, PCWorld, and The Verge) on Google's plan to
  move ChromeOS onto an Android-based platform, with ChromeOS support reported to continue until at least
  2034. Dates and scope were unconfirmed when this skill was written; check Google's own announcements.
- Community guides to Chromebook developer mode (Android Police, Android Central): useful for
  describing the boot screens; key sequences and timing vary by model and release, so verify on the
  Chromium page above.
